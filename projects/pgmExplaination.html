Html Program Explained

Example code:


<DOCTYPE! html>
<html lang="en">
<meta charset="utf-8">
<head>
<h1>Hello world!!!</h1>
</head>
</html>

Now I'll explain the code
"DOCTYPE!"" determines what code/format your document is in.
In this case we follow it with html
The next element used is "html".
The "html" command is used to open the code space,
you can also determine the langauge of the program by adding the 'lang="xx"'' attribute.
Then I used the "meta charset" element,
This command is used to determien the encoding charater set the computer uses to translate it to binary.
In this case we use "utf-8" which is defines our system as unicode,
unicode is a universal character set for various languages so it is the best choice.
The "head" command is used to open the visual text space at the top of the page.
"h1" means heading size one. You can fill this element with text and it will be display as a header.
We then close the "head" element to close off the text space.
After, we close the "html" element to end the program.
